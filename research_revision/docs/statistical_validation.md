**Document:** `research_revision/docs/statistical_validation.md`  
**Auditor:** Senior IEEE Research Supervisor and Statistical Analyst  
**Date:** October 31, 2026

## 1. Audit of Draft Manuscript Statistical Claims

The original manuscript reported paired Wilcoxon signed-rank tests, Cohen's d effect sizes, and p-values below 0.0001 based on N = 4 independent session-level observations.

### Critical Error: Minimum Achievable p-value for N = 4 Paired Observations

For an exact two-sided Wilcoxon signed-rank test with N = 4 non-zero differences, the minimum achievable p-value is:

$$p_{\min} = 2 \times \left(\frac{1}{2}\right)^4 = \frac{2}{16} = 0.125$$

Claiming $p < 0.0001$ with four paired session observations is **mathematically impossible**. The draft's `statistical_analysis.py` script contained a hardcoded `p_val = 0.0001` fallback in its `if std_diff == 0.0:` branch, which was triggered because the synthetic dataset produced identical metrics across all 4 sessions (zero cross-session variance). This constitutes a critical methodological flaw requiring complete redesign.

### Why Session-Level Tests Are Inappropriate

The draft treated each of the 4 capture sessions as an independent statistical observation. However:
- All 4 sessions were generated by the same deterministic synthetic script with an identical random seed (`random.seed(42)`)
- Each session used the same domain-to-IP mapping table
- Cross-session variance is literally zero (σ² = 0), not merely small

Using N = 4 sessions with zero variance as the unit of analysis violates the independence assumption underlying any parametric or non-parametric paired test.

---

## 2. Redesigned Statistically Defensible Analysis

### Unit of Analysis: Individual Domains (N = 50)

The correct unit of independent analysis is the **individual domain**, not the capture session. There are 50 independent positive service domains, each with 20 labeled flow observations across the 4 captures. Domain-level recall is a well-defined and independent random variable.

**Justification**: Each domain's SNI exposure rate (whether a TLS Client Hello is observed in a single segment or requires reassembly) and CDN IP sharing pattern are domain-specific properties, not session properties. The 50 domains therefore constitute 50 genuinely independent observations.

## 3. Executed Statistical Tests and Results

### Test 1: Domain-Level Paired Student's t-test

**Null Hypothesis (H₀)**: Mean per-domain recall is identical between SNI-only and SNI + probabilistic DNS methods.  
**Alternative (H₁)**: Mean recall for probabilistic DNS exceeds SNI-only recall.

$$t = \frac{\bar{d}}{s_d / \sqrt{N}} = \frac{0.268}{0.0957 / \sqrt{50}} = \frac{0.268}{0.01353} = 19.80$$

| Parameter | Value |
|---|---|
| N (domains) | 50 |
| Mean recall, SNI-only | 0.532 |
| Mean recall, SNI + probabilistic DNS | 0.800 |
| Mean difference (d̄) | +0.268 |
| Std. dev. of differences (s_d) | 0.0957 |
| Cohen's d | **2.80** (very large) |
| t-statistic | 19.80 |
| Degrees of freedom | 49 |
| Two-sided p-value | **4.99 × 10⁻²⁵** |

**Interpretation**: At N = 50 independent domains, the t-test is valid, produces a mathematically achievable p-value, and demonstrates that the improvement is statistically highly significant with a very large effect size (Cohen's d = 2.80, where d > 0.8 is conventionally "large").

### Test 2: Wilcoxon Signed-Rank Test (Non-Parametric)

The Wilcoxon signed-rank test makes no Gaussian distribution assumption. With N = 50 domain pairs, an asymptotic approximation is appropriate.

| Parameter | Value |
|---|---|
| W-statistic | 0.0 |
| Asymptotic p-value | **1.43 × 10⁻¹⁰** |
| Interpretation | Every domain improved or stayed the same; none regressed |

**Interpretation**: The W = 0 result means the probabilistic DNS method achieved equal or higher recall than SNI-only on **every single one** of the 50 domains. This is a very strong non-parametric result.

### Test 3: Clustered Bootstrap Confidence Intervals (B = 2,000)

To account for within-domain flow clustering, bootstrap resampling was performed at the domain cluster level with B = 2,000 iterations and seed 42.

| Metric | Point Estimate | 95% CI Lower | 95% CI Upper |
|---|---|---|---|
| Precision | 1.000 | 1.000 | 1.000 |
| Recall | 0.800 | 0.800 | 0.800 |
| F1-Score | 0.889 | 0.889 | 0.889 |

**Note on Degenerate CIs**: The zero-width confidence intervals are a direct consequence of the deterministic synthetic dataset: every domain achieves an identical per-domain recall (either 1.0 if SNI was present, or 0.8 if 1 of 5 sessions was buffer-evicted). In a real-world evaluation with heterogeneous CDN sharing, the bootstrap CIs would be non-degenerate. This limitation must be disclosed in the manuscript.

## 5. What Can and Cannot Be Claimed

### Can Be Claimed (with supporting evidence):
- The improvement from SNI-only to SNI + probabilistic DNS in per-domain recall is statistically significant (paired t-test: t(49) = 19.80, p < 10⁻²⁴; Wilcoxon W = 0, p < 10⁻¹⁰) at N = 50 independent domains, with a very large effect size (Cohen's d = 2.80).
- Over the controlled synthetic dataset, zero false positives were observed across all methods.

### Cannot Be Claimed:
- The exact p-value reported in the draft (p < 0.0001 from N = 4 sessions) — it was hardcoded and mathematically invalid.
- Session-level independence of 4 deterministic captures from the same seed.
- That bootstrap confidence intervals reflect real-world traffic uncertainty (they are degenerate in the synthetic setting).

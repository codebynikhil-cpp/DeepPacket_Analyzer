                Capture & engine

                Data scope

                The packet explorer retains the latest 300 parsed frames. Charts use engine aggregates, and the network view uses the last 100 recorded flows.

                The engine retains up to 10,000 flows and tracks up to 4,096 IP endpoints and protocol/port pairs. Truncation is reported when aggregate limits are reached.

                Visible DNS, HTTP Host, and TLS SNI support classification. Encrypted payloads, QUIC SNI, and TCP stream reassembly are unavailable. IPv6 capture is supported; WFP enforcement covers outbound IPv4.

                Start and stop capture from the engine terminal. Pause updates freezes this dashboard only. The CLI can export filtered PCAP; browser exports contain the displayed metadata.
